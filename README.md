# CV Generator

Outil de création de CV professionnel directement depuis le navigateur — sans inscription, sans installation.

🔗 **Demo live** : [cv-gen-hg.netlify.app](https://cv-gen-hg.netlify.app)

## Stack
React · Vite · html2pdf.js · Netlify

## Fonctionnalités
- Landing page animée avec effet typewriter
- Formulaire guidé en 4 étapes avec validation
- Aperçu du CV en temps réel
- 4 thèmes couleur : Bleu Marine, Vert Forêt, Bordeaux, Anthracite
- Upload photo de profil
- Export PDF format A4
- Bilingue FR / EN

## Lancer en local
```bash
npm install
npm run dev
```

## Pourquoi ce projet ?
Créer un CV propre reste un obstacle pour beaucoup — surtout sans accès à Word ou Canva. CV Generator rend ça accessible directement depuis le navigateur, sans friction.
